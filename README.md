# 摄影棚灯光方案与设备占用排期系统

摄影师在平面图上安排灯位、填写器材清单；场务核对实物、回路负载后确认时段。
确认时同时占用**场地**与每一盏**灯具**，拍摄结束逐件登记归还，损坏记录关联项目。

- 后端：Rust + Axum 0.8 + SQLx + SQLite（WAL，自动迁移）
- 前端：Svelte 4 + Vite（构建后由后端静态托管，单端口）
- 功率读数、通知均为本地模拟

## 一条命令启动

```bash
./run.sh              # 默认 http://localhost:8080
PORT=9000 ./run.sh    # 自定义端口
```

首次运行自动：安装前端依赖 → 构建前端 → 编译后端 → 建库迁移 → 写入演示数据
（2 个摄影棚、6 条 2000W 回路、7 盏灯具、2 名摄影师 + 1 名场务）。

演示账号（右上角切换身份）：

| 身份 | 姓名 | 权限 |
|---|---|---|
| 摄影师 | 陈曦 / 林夏 | 建项目、画布布光、保存版本、提交、变更、取消 |
| 场务 | 老周 | 预检、确认/驳回、逐件归还、损坏豁免审批 |

## 验证（46 项断言）

```bash
python3 verify.py      # 自动启动独立测试库，跑完即停
```

覆盖的关键规则：

1. **设备互斥**：同一灯具（跨场地同样生效）在重叠时段不能被两组占用，确认时在
   `BEGIN IMMEDIATE` 事务内扫描，杜绝并发双确认。
2. **回路阈值**：本方案功率 + 同时段其他项目已占用功率 > 回路上限时，预检与确认都
   返回 409；即使请求体带 `force: true` 也返回 403——**不存在手工放行通道**。
3. **取消即释放**：取消项目在同一事务内删除 venue/fixture slots，随后立刻可被其他
   项目确认（验证脚本顺序验证了"取消前 409 → 取消后 200"）。
4. **逐件归还**：每归还一件，该灯具的 fixture_slot 立即删除、恢复可借；全部归还后
   释放场地、项目完成。损坏件生成关联本项目的损坏记录。
5. **豁免权限**：摄影师（包括其他摄影师角色用户）不能审批损坏豁免，仅场务可审批，
   且服务端校验审批人不是本项目摄影师。
6. **版本与重新确认**：每次保存/变更追加 `plan_versions`（永不覆盖）；换灯或延时
   走 replan：先预检新方案（不通过则**旧占用原样保留**）→ 释放旧占用 → 新版本 →
   回到待确认 → 场务重新确认，全部历史（confirmed/rejected/revoked）可追溯。
7. 半开区间 `[start, end)`：首尾相接的时段不算冲突。

## 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/meta` | 用户 / 场地 / 回路 / 灯具 |
| GET/POST | `/api/projects` | 项目列表 / 新建（摄影师） |
| GET/PATCH | `/api/projects/{id}` | 详情 / 改时段场地（草稿期） |
| POST | `/api/projects/{id}/versions` | 保存方案新版本（灯位+清单） |
| POST | `/api/projects/{id}/submit` | 摄影师提交 |
| POST | `/api/projects/{id}/check` | 预检：互斥 + 场地 + 回路负载 |
| POST | `/api/projects/{id}/confirm` | 场务确认（强校验，force 无效） |
| POST | `/api/projects/{id}/reject` | 场务驳回（回草稿） |
| POST | `/api/projects/{id}/replan` | 换灯/延时：释放旧占用→待重确 |
| POST | `/api/projects/{id}/cancel` | 取消：立即释放全部资源 |
| POST | `/api/projects/{id}/returns` | 逐件归还（ok / damaged） |
| GET | `/api/projects/{id}/sim-power` | 本地模拟各回路实时功率 |
| POST | `/api/damages/{id}/decision` | 豁免审批（场务，非项目摄影师） |
| GET | `/api/timeline` | 场地 + 灯具甘特图数据 |
| GET | `/api/notifications` | 模拟通知流 |

## 页面

- **项目方案**：新建项目、可拖拽灯位平面图（按米网格、越界校验）、器材清单
  （实物灯具 / 回路 / 功率 / 标签）、回路负载条、版本查看。
- **占用时段**：场地与灯具的甘特视图，按项目着色，点击跳转。
- 项目详情内：场务预检面板（逐条列出冲突与各回路"已有+新增=合计/上限"）、
  逐件归还、损坏豁免、模拟电表读数、版本与确认历史。
